# Code of Conduct

## Our Standards

Participants in this project are expected to:

- be respectful and constructive
- assume good intent
- give actionable technical feedback
- keep discussion focused on the work
- avoid harassment, discrimination, and personal attacks

## Unacceptable Behavior

Examples of unacceptable behavior include:

- insulting or hostile language
- harassment or intimidation
- discriminatory remarks
- bad-faith disruption of discussions or pull requests
- publishing private information without permission

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, or other contributions that violate this code of conduct.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer privately through the repository contact method or GitHub features available for maintainers.
