# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue.

Instead:

1. Report it privately through GitHub security advisories if enabled.
2. Or contact the maintainer directly through the repository contact method.

Please include:

- affected package version
- Laravel version
- PHP version
- reproduction steps
- impact assessment
- proof of concept if available

You will receive an acknowledgment once the report is reviewed.

## Scope

Security reports should focus on vulnerabilities in the package itself, such as:

- unsafe generated code patterns
- privilege escalation through generated defaults
- insecure file generation behavior
- dangerous assumptions in request handling or route generation
